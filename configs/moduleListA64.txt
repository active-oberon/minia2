# The headless standard library, in dependency order, for the AArch64 target.
#
# It is the list of docker/headless-core.txt in the order Release.Build prints for Linux64, less
# four modules that cannot exist on this architecture:
#
#	CPUID				the x86 instruction of that name
#	Shortreal			half precision floats through the AVX F16C instructions
#	FoxArrayBaseOptimized	the x86 kernels of the array runtime; FoxArrayBase loads them by name
#				if they are there and works without them if they are not
#	Beep				imports Displays and XDisplay, which are not headless
